Custom UI orchestrates the path. MLflow keeps the system of record for runs, artifacts, and the registry.

01 · Experiment

Create or select an experiment

Training and evaluation runs live in one MLflow Tracking experiment. Production is later a registry alias on this same MLflow instance — not a second experiment.

    Promotion assigns a Model Registry alias (champion / challenger) on the same MLflow server. That is the production pointer — not a new experiment.

    Serve models:/name@champion

    Inference loads the alias. Optional MLflow traces land in workbench-production-traces for monitoring — they are not training runs.
